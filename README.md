## 🚧 What I’m building

### 🚀 CareerCraft
> *Build your future. One application at a time.*

A career development and job application platform: CV building and PDF export first, then application tracking and tools for career progress. I’m building it milestone by milestone as a way to learn modern frontend development properly. **Status:** in development, working on the landing page.
